↓ Descargar para Windows

Versión 1.2.2 · Windows de 64 bits · Instalador .exe

Cómo instalar

  1. Pulsa Descargar para Windows.
  2. Abre Galaxia-IA-1.2.2-Setup.exe y sigue el instalador.
  3. Abre Galaxia IA y entra o crea tu cuenta local. Conecta tus proveedores o una invitación compartida para usar las IA.

La cuenta local y la cuenta web son independientes. La app conserva los datos locales al actualizarse y busca nuevas versiones automáticamente.

La descarga es gratis. Las API pueden consumir saldo del proveedor. La IA local requiere un modelo instalado en tu PC.
